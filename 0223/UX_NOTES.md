# Sales Arena — Экспедитор: редизайн мобильного UI

**Роль:** Экспедитор (доставка, приём оплаты, возвраты, синхронизация с кассой/складом).
**Платформа:** Android, 360–430 dp, светлая тема для полевой работы.
**Языки:** chrome (табы, меню, заголовки) — русский; статусы заказа/оплаты/возврата — узбекский.

Интерактивный прототип: `design/index.html` (откройте в браузере — слева навигация по 50 экранам,
вверху — IA-схема, компоненты, токены, UX-заметки).

---

Сигнальный оранжевый `#D9580F` — «движение/доставка». Он отделяет экспедитора от нейтральных
сине-фиолетовых тем агента и супервайзера. Статусы:

Накладные: «Ожидание подтверждения» (amber), «Подтвержден» (green). Полная палитра и токены — на
странице «Токены» в прототипе.

## 2. Структура (сохранена 1:1)

- Нижние табы: **Главная · Визиты · Должники · Накладные**.
- Drawer: Главная, Дополнительные визиты, Изменение оплаты*, Возврат / догрузка*,
  Мои возвраты, Остаток в машине, Незавершённые заказы, Поделиться («Скоро!»), Настройки,
  Выйти из аккаунта; футер с версией. (`*` — по флагам конфигурации.)
- «Остаток в машине» — **инвентарь кузова** (наименования / остаток vs загружено), не список доставок.

## 4. Главные решения

1. **Визит = сессия.** «Начать визит» → таймер сеанса + «Завершить» + «Добавить оплату» в одной
   нижней панели. До старта действия по статусам заблокированы одним лок-сообщением.
2. **Оплата не завершается мгновенно.** Все заявки получают «Tasdiqlanmoqda» (amber pulse) и
   подтверждаются кассой в web («Заявки на оплату экспедиторов»). Возврат оплаты — баннер
   «To'lovni to'g'rilash kerak» с таймером и кнопкой «To'g'rilash».
3. **Три уровня оплат:** счётчик на Главной → sheet «Оплаты» → полная «Информация оплаты».
4. **Синхронизация отделена:** выбор (полная/обычная) → шаги → прогресс → готово/ошибка/повтор;
   офлайн-пилюля объясняет локальное хранение.
5. **Выключенные конфиги не «пропадают»:** вместо пустоты — объяснение на UZ.
6. **Бейджи статусов:** точка-индикатор + текст; pulse у «Tasdiqlanmoqda»; долг — красная
   карточка; «Просрочено N дн» — красный бейдж.
7. **Успеваемость** — кольцо на Главной (УСПЕВАЕМОСТЬ: Посещено / Осталось / последняя синхронизация).

## 5. Что упрощено

- Единый визуальный язык статусов вместо разрозненных текстов.
- Крупные сенсорные зоны (кнопки ≥ 48 dp), табулярные цифры для сумм.
- «Начать визит» в 2–3 касания (Визиты → карточка → CTA).
- Ошибки синхронизации с шагом-указателем и повторной попыткой.

## 6. Что сохранено без изменений

- Весь состав табов, меню, статусов, способов оплаты (Naqd/Карта/Terminal/Pereches), причин возврата.
- Правила: «Bekor qilindi» экспедитор не меняет; возврат с полки/догрузка/бонусы; акт сверки,
  баланс по агентам, незавершённые заказы, легаси-экран заказа (deep link) с 5 действиями.

## 7. Состояния (empty / loading / error / offline)

- **Empty:** «Пока здесь пусто», «Незавершённых заказов нет», «В машине нет товаров»,
  «Нет новых уведомлений».
- **Loading:** сплэш, bootstrap, синхронизация, «Определяем геолокацию…», «Начинаем…», скелетоны.
- **Error:** «Ошибка: …» с повтором; код ошибки возврата (напр. `RETURN_DISABLED`) — человеческий RU-текст.
- **Offline:** пилюля «Нет соединения · изменения сохраняются локально», отложенная отправка заявок.
